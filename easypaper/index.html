논문 PDF를 열어 보세요

문단에 마우스를 올리면 그 문단의 번역이 나타납니다.
문단을 클릭하면 번역 창이 고정되어 글을 복사할 수 있습니다.

  1. 설정에서 모델을 고르고 API 키를 입력합니다.
  2. PDF를 열거나 이 창에 끌어다 놓습니다.
  3. ‘번역 시작’을 누르고 읽고 싶은 문단에 마우스를 올립니다.

PDF는 이 브라우저 안에서만 열리고, 추출한 문단 텍스트만 선택한 AI 제공자에게 전송됩니다. API 키와 번역 결과는 이 브라우저에만 저장되며, 한 번 번역한 문단은 다시 열어도 비용이 들지 않습니다.

클릭하면 고정
여기에 놓으면 PDF가 열립니다

설정

OpenAI 호환 API의 기본 주소로, /chat/completions 앞부분까지 적습니다. 브라우저에서 바로 호출하는 것(CORS)을 허용하는 API만 쓸 수 있습니다.

키 발급받기 ↗

키는 번역을 요청할 때 선택한 제공자에게만 전송됩니다. 저장을 끄면 탭을 닫을 때 지워집니다.
