위쪽 Edit 영역에는 현재 편집의 설명이, 아래 두 개의 코드 영역에는 변경 전과 후의 코드가 표시됩니다.

  • Edit 아래의 Prev / Next 링크로 Edit #1-6을 순서대로 볼 수 있습니다.
  • 편집 설명이나 코드에서 색이 칠해진 부분을 클릭하면, 관련 노드로 스크롤되며 강조 표시됩니다.
  • Clear 링크를 클릭하면 강조 표시가 제거됩니다.
  • 아래 색상은 각각 다음을 의미합니다:
    • Insert : 노드/서브트리 삽입
    • Delete : 노드/서브트리 삭제
    • Move : 노드/서브트리 이동
    • Update : 노드의 텍스트 변경 (변수 이름, 숫자/문자열 리터럴 등)
