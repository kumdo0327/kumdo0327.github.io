Introduction

본 설문은 Abstract Syntax Tree 기반의 코드 차이 비교 기법(tree differencing)에 대한 연구를 목적으로 진행됩니다.

설문에서는 각 소스 코드 변경에 대해 두 가지 코드 차이 시각화 결과(A, B)가 제시됩니다. 참가자에게 요구되는 판단 기준은 다음과 같습니다.

"버전 A와 B의 시각화 결과 중 어느 쪽이 코드 변경의 의도를 이해하는 데 더 도움이 되는가?"

각 문항마다 세 가지의 선택지가 주어집니다.

  • A (A를 더 선호함)
  • B (B를 더 선호함)
  • Unclear (둘 중 어느 것이 더 나은지 판단하기 어려움)

버전 A와 B의 표기는 임의적으로 부여된 것이며, A와 B에 해당되는 tree differencing 기술은 문항마다 다릅니다. 설문은 총 30문항으로 다음과 같이 구성되어있습니다.

  • Java (1 ~ 10)
  • C/C++ (11 ~ 20)
  • Python (21 ~ 30)
