  1 """ 
  2 Colormap Normalization 
  3 ====================== 
  4  
  5 Objects that use colormaps by default linearly map the colors in the 
  6 colormap from data values *vmin* to *vmax*.  For example:: 
  7  
  8     pcm = ax.pcolormesh(x, y, Z, vmin=-1., vmax=1., cmap='RdBu_r') 
  9  
 10 will map the data in *Z* linearly from -1 to +1, so *Z=0* will 
 11 give a color at the center of the colormap *RdBu_r* (white in this 
 12 case). 
 13  
 14 Matplotlib does this mapping in two steps, with a normalization from 
 15 the input data to [0, 1] occurring first, and then mapping onto the 
 16 indices in the colormap.  Normalizations are classes defined in the 
 17 :func:`matplotlib.colors` module.  The default, linear normalization 
 18 is :func:`matplotlib.colors.Normalize`. 
 19  
 20 Artists that map data to color pass the arguments *vmin* and *vmax* to 
 21 construct a :func:`matplotlib.colors.Normalize` instance, then call it: 
 22  
 23 .. ipython:: 
 24  
 25    In [1]: import matplotlib as mpl 
 26  
 27    In [2]: norm = mpl.colors.Normalize(vmin=-1, vmax=1) 
 28  
 29    In [3]: norm(0) 
 30    Out[3]: 0.5 
 31  
 32 However, there are sometimes cases where it is useful to map data to 
 33 colormaps in a non-linear fashion. 
 34  
 35 Logarithmic 
 36 ----------- 
 37  
 38 One of the most common transformations is to plot data by taking its logarithm 
 39 (to the base-10).  This transformation is useful to display changes across 
 40 disparate scales.  Using `.colors.LogNorm` normalizes the data via 
 41 :math:`log_{10}`.  In the example below, there are two bumps, one much smaller 
 42 than the other. Using `.colors.LogNorm`, the shape and location of each bump 
 43 can clearly be seen: 
 44  
 45 """ 
 46 import numpy as np 
 47 import matplotlib.pyplot as plt 
 48 import matplotlib.colors as colors 
 49 import matplotlib.cbook as cbook 
 50  
 51 N = 100 
 52 X, Y = np.mgrid[-3:3:complex(0, N), -2:2:complex(0, N)] 
 53  
 54 # A low hump with a spike coming out of the top right.  Needs to have 
 55 # z/colour axis on a log scale so we see both hump and spike.  linear 
 56 # scale only shows the spike. 
 57 Z1 = np.exp(-X**2 - Y**2) 
 58 Z2 = np.exp(-(X * 10)**2 - (Y * 10)**2) 
 59 Z = Z1 + 50 * Z2 
 60  
 61 fig, ax = plt.subplots(2, 1) 
 62  
 63 pcm = ax[0].pcolor(X, Y, Z, 
 64                    norm=colors.LogNorm(vmin=Z.min(), vmax=Z.max()), 
 65                    cmap='PuBu_r') 
 66 fig.colorbar(pcm, ax=ax[0], extend='max') 
 67  
 68 pcm = ax[1].pcolor(X, Y, Z, cmap='PuBu_r') 
 69 fig.colorbar(pcm, ax=ax[1], extend='max') 
 70 plt.show()

 73 # Symmetric logarithmic 
 74 # --------------------- 
 75 # 
 76 # Similarly, it sometimes happens that there is data that is positive 
 77 # and negative, but we would still like a logarithmic scaling applied to 
 78 # both.  In this case, the negative numbers are also scaled 
 79 # logarithmically, and mapped to smaller numbers; e.g., if ``vmin=-vmax``, 
 80 # then they the negative numbers are mapped from 0 to 0.5 and the 
 81 # positive from 0.5 to 1. 
 82 # 
 83 # Since the logarithm of values close to zero tends toward infinity, a 
 84 # small range around zero needs to be mapped linearly.  The parameter 
 85 # *linthresh* allows the user to specify the size of this range 
 86 # (-*linthresh*, *linthresh*).  The size of this range in the colormap is 
 87 # set by *linscale*.  When *linscale* == 1.0 (the default), the space used 
 88 # for the positive and negative halves of the linear range will be equal 
 89 # to one decade in the logarithmic range. 
 90  
 91 N = 100 
 92 X, Y = np.mgrid[-3:3:complex(0, N), -2:2:complex(0, N)] 
 93 Z1 = np.exp(-X**2 - Y**2) 
 94 Z2 = np.exp(-(X - 1)**2 - (Y - 1)**2) 
 95 Z = (Z1 - Z2) * 2 
 96  
 97 fig, ax = plt.subplots(2, 1) 
 98  
 99 pcm = ax[0].pcolormesh(X, Y, Z, 
100                        norm=colors.SymLogNorm(linthresh=0.03, linscale=0.03, 
101                                               vmin=-1.0, vmax=1.0), 
102                        cmap='RdBu_r') 
103 fig.colorbar(pcm, ax=ax[0], extend='both') 
104  
105 pcm = ax[1].pcolormesh(X, Y, Z, cmap='RdBu_r', vmin=-np.max(Z)) 
106 fig.colorbar(pcm, ax=ax[1], extend='both') 
107 plt.show()

230 # Custom normalization: Manually implement two linear ranges

233 # The `.TwoSlopeNorm` described above makes a useful example for

236 class MidpointNormalize(colors.Normalize):

238         self.vcenter = vcenter 
239         colors.Normalize.__init__(self, vmin, vmax, clip) 
240  
241     def __call__(self, value, clip=None): 
242         # I'm ignoring masked values and all kinds of edge cases to make a 
243         # simple example... 
244         x, y = [self.vmin, self.vcenter, self.vmax], [0, 0.5, 1] 
245         return np.ma.masked_array(np.interp(value, x, y))
