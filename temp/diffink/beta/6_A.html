 79     List<Node> parseFragment(String inputFragment, Element context, String baseUri, ParseErrorList errors, ParseSettings settings) { 
 80         // context may be null 
 81         state = HtmlTreeBuilderState.Initial; 
 82         initialiseParse(new StringReader(inputFragment), baseUri, errors, settings); 
 83         contextElement = context; 
 84         fragmentParsing = true; 
 85         Element root = null; 
 86  
 87         if (context != null) { 
 88             if (context.ownerDocument() != null) // quirks setup: 
 89                 doc.quirksMode(context.ownerDocument().quirksMode()); 
 90  
 91             // initialise the tokeniser state: 
 92             String contextTag = context.tagName(); 
 93             if (StringUtil.in(contextTag, "title", "textarea")) 
 94                 tokeniser.transition(TokeniserState.Rcdata); 
 95             else if (StringUtil.in(contextTag, "iframe", "noembed", "noframes", "style", "xmp")) 
 96                 tokeniser.transition(TokeniserState.Rawtext); 
 97             else if (contextTag.equals("script")) 
 98                 tokeniser.transition(TokeniserState.ScriptData); 
 99             else if (contextTag.equals(("noscript"))) 
100                 tokeniser.transition(TokeniserState.Data); // if scripting enabled, rawtext 
101             else if (contextTag.equals("plaintext")) 
102                 tokeniser.transition(TokeniserState.Data); 
103             else 
104                 tokeniser.transition(TokeniserState.Data); // default 
105  
106             root = new Element(Tag.valueOf("html", settings), baseUri); 
107             doc.appendChild(root); 
108             stack.add(root); 
109             resetInsertionMode(); 
110  
111             // setup form element to nearest form on context (up ancestor chain). ensures form controls are associated 
112             // with form correctly 
113             Elements contextChain = context.parents(); 
114             contextChain.add(0, context); 
115             for (Element parent: contextChain) { 
116                 if (parent instanceof FormElement) { 
117                     formElement = (FormElement) parent; 
118                     break; 
119                 } 
120             } 
121         } 
122  
123         runParser(); 
124         if (context != null) 
125             return root.childNodes(); 
126         else 
127             return doc.childNodes(); 
128     }

194     Element insert(Token.StartTag startTag) { 
195         // handle empty unknown tags 
196         // when the spec expects an empty tag, will directly hit insertEmpty, so won't generate this fake end tag. 
197         if (startTag.isSelfClosing()) { 
198             Element el = insertEmpty(startTag); 
199             stack.add(el); 
200             tokeniser.transition(TokeniserState.Data); // handles <script />, otherwise needs breakout steps from script data 
201             tokeniser.emit(emptyEnd.reset().name(el.tagName()));  // ensure we get out of whatever state we are in. emitted for yielded processing 
202             return el; 
203         } 
204          
205         Element el = new Element(Tag.valueOf(startTag.name(), settings), baseUri, settings.normalizeAttributes(startTag.attributes)); 
206         insert(el); 
207         return el; 
208     }

263         // if the stack hasn't been set up yet, elements (doctype, comments) go into the doc 
264         if (stack.size() == 0)

404     void resetInsertionMode() { 
405         boolean last = false; 
406         for (int pos = stack.size() -1; pos >= 0; pos--) { 
407             Element node = stack.get(pos); 
408             if (pos == 0) { 
409                 last = true; 
410                 node = contextElement; 
411             } 
412             String name = node.nodeName(); 
413             if ("select".equals(name)) { 
414                 transition(HtmlTreeBuilderState.InSelect); 
415                 break; // frag 
416             } else if (("td".equals(name) || "th".equals(name) && !last)) { 
417                 transition(HtmlTreeBuilderState.InCell); 
418                 break; 
419             } else if ("tr".equals(name)) { 
420                 transition(HtmlTreeBuilderState.InRow); 
421                 break; 
422             } else if ("tbody".equals(name) || "thead".equals(name) || "tfoot".equals(name)) { 
423                 transition(HtmlTreeBuilderState.InTableBody); 
424                 break; 
425             } else if ("caption".equals(name)) { 
426                 transition(HtmlTreeBuilderState.InCaption); 
427                 break; 
428             } else if ("colgroup".equals(name)) { 
429                 transition(HtmlTreeBuilderState.InColumnGroup); 
430                 break; // frag 
431             } else if ("table".equals(name)) { 
432                 transition(HtmlTreeBuilderState.InTable); 
433                 break; 
434             } else if ("head".equals(name)) { 
435                 transition(HtmlTreeBuilderState.InBody); 
436                 break; // frag 
437             } else if ("body".equals(name)) { 
438                 transition(HtmlTreeBuilderState.InBody); 
439                 break; 
440             } else if ("frameset".equals(name)) { 
441                 transition(HtmlTreeBuilderState.InFrameset); 
442                 break; // frag 
443             } else if ("html".equals(name)) { 
444                 transition(HtmlTreeBuilderState.BeforeHead); 
445                 break; // frag 
446             } else if (last) { 
447                 transition(HtmlTreeBuilderState.InBody); 
448                 break; // frag 
449             } 
450         }

616     void reconstructFormattingElements() { 
617         Element last = lastFormattingElement(); 
618         if (last == null || onStack(last)) 
619             return; 
620  
621         Element entry = last; 
622         int size = formattingElements.size(); 
623         int pos = size - 1; 
624         boolean skip = false; 
625         while (true) { 
626             if (pos == 0) { // step 4. if none before, skip to 8 
627                 skip = true; 
628                 break; 
629             } 
630             entry = formattingElements.get(--pos); // step 5. one earlier than entry 
631             if (entry == null || onStack(entry)) // step 6 - neither marker nor on stack 
632                 break; // jump to 8, else continue back to 4 
633         } 
634         while(true) { 
635             if (!skip) // step 7: on later than entry 
636                 entry = formattingElements.get(++pos); 
637             Validate.notNull(entry); // should not occur, as we break at last element 
638  
639             // 8. create new element from element, 9 insert into current node, onto stack 
640             skip = false; // can only skip increment from 4. 
641             Element newEl = insertStartTag(entry.nodeName()); // todo: avoid fostering here? 
642             // newEl.namespace(entry.namespace()); // todo: namespaces 
643             newEl.attributes().addAll(entry.attributes()); 
644  
645             // 10. replace entry with new entry 
646             formattingElements.set(pos, newEl); 
647  
648             // 11 
649             if (pos == size-1) // if not last entry in list, jump to 7 
650                 break; 
651         } 
652     }

 79     List<Node> parseFragment(String inputFragment, Element context, String baseUri, ParseErrorList errors, ParseSettings settings) { 
 80         // context may be null 
 81         state = HtmlTreeBuilderState.Initial; 
 82         initialiseParse(new StringReader(inputFragment), baseUri, errors, settings); 
 83         contextElement = context; 
 84         fragmentParsing = true; 
 85         Element root = null; 
 86  
 87         if (context != null) { 
 88             if (context.ownerDocument() != null) // quirks setup: 
 89                 doc.quirksMode(context.ownerDocument().quirksMode()); 
 90  
 91             // initialise the tokeniser state: 
 92             String contextTag = context.tagName(); 
 93             if (StringUtil.in(contextTag, "title", "textarea")) 
 94                 tokeniser.transition(TokeniserState.Rcdata); 
 95             else if (StringUtil.in(contextTag, "iframe", "noembed", "noframes", "style", "xmp")) 
 96                 tokeniser.transition(TokeniserState.Rawtext); 
 97             else if (contextTag.equals("script")) 
 98                 tokeniser.transition(TokeniserState.ScriptData); 
 99             else if (contextTag.equals(("noscript"))) 
100                 tokeniser.transition(TokeniserState.Data); // if scripting enabled, rawtext 
101             else if (contextTag.equals("plaintext")) 
102                 tokeniser.transition(TokeniserState.Data); 
103             else 
104                 tokeniser.transition(TokeniserState.Data); // default 
105  
106             root = new Element(Tag.valueOf("html", settings), baseUri);

112             // with form correctly

404     void resetInsertionMode() { 
405         boolean last = false; 
406         for (int pos = stack.size() -1; pos >= 0; pos--) { 
407             Element node = stack.get(pos); 
408             if (pos == 0) { 
409                 last = true; 
410                 node = contextElement; 
411             } 
412             String name = node.nodeName(); 
413             if ("select".equals(name)) { 
414                 transition(HtmlTreeBuilderState.InSelect); 
415                 break; // frag 
416             } else if (("td".equals(name) || "th".equals(name) && !last)) { 
417                 transition(HtmlTreeBuilderState.InCell); 
418                 break; 
419             } else if ("tr".equals(name)) { 
420                 transition(HtmlTreeBuilderState.InRow); 
421                 break; 
422             } else if ("tbody".equals(name) || "thead".equals(name) || "tfoot".equals(name)) { 
423                 transition(HtmlTreeBuilderState.InTableBody); 
424                 break; 
425             } else if ("caption".equals(name)) { 
426                 transition(HtmlTreeBuilderState.InCaption); 
427                 break; 
428             } else if ("colgroup".equals(name)) { 
429                 transition(HtmlTreeBuilderState.InColumnGroup); 
430                 break; // frag 
431             } else if ("table".equals(name)) { 
432                 transition(HtmlTreeBuilderState.InTable); 
433                 break; 
434             } else if ("head".equals(name)) { 
435                 transition(HtmlTreeBuilderState.InBody); 
436                 break; // frag 
437             } else if ("body".equals(name)) { 
438                 transition(HtmlTreeBuilderState.InBody); 
439                 break; 
440             } else if ("frameset".equals(name)) { 
441                 transition(HtmlTreeBuilderState.InFrameset); 
442                 break; // frag 
443             } else if ("html".equals(name)) { 
444                 transition(HtmlTreeBuilderState.BeforeHead); 
445                 break; // frag 
446             } else if (last) { 
447                 transition(HtmlTreeBuilderState.InBody); 
448                 break; // frag 
449             } 
450         }

616     void reconstructFormattingElements() { 
617         Element last = lastFormattingElement(); 
618         if (last == null || onStack(last)) 
619             return; 
620  
621         Element entry = last; 
622         int size = formattingElements.size(); 
623         int pos = size - 1; 
624         boolean skip = false; 
625         while (true) { 
626             if (pos == 0) { // step 4. if none before, skip to 8 
627                 skip = true; 
628                 break; 
629             } 
630             entry = formattingElements.get(--pos); // step 5. one earlier than entry 
631             if (entry == null || onStack(entry)) // step 6 - neither marker nor on stack 
632                 break; // jump to 8, else continue back to 4 
633         } 
634         while(true) { 
635             if (!skip) // step 7: on later than entry 
636                 entry = formattingElements.get(++pos); 
637             Validate.notNull(entry); // should not occur, as we break at last element 
638  
639             // 8. create new element from element, 9 insert into current node, onto stack 
640             skip = false; // can only skip increment from 4. 
641             Element newEl = insertStartTag(entry.nodeName()); // todo: avoid fostering here? 
642             // newEl.namespace(entry.namespace()); // todo: namespaces 
643             newEl.attributes().addAll(entry.attributes()); 
644  
645             // 10. replace entry with new entry 
646             formattingElements.set(pos, newEl); 
647  
648             // 11 
649             if (pos == size-1) // if not last entry in list, jump to 7 
650                 break; 
651         } 
652     }

677         for (int pos = formattingElements.size() -1; pos >= 0; pos--) { 
678             Element next = formattingElements.get(pos); 
679             if (next == null) // scope marker 
680                 break; 
681             else if (next.nodeName().equals(nodeName)) 
682                 return next; 
683         } 
684         return null; 
685     }

695     void insertInFosterParent(Node in) { 
696         Element fosterParent; 
697         Element lastTable = getFromStack("table"); 
698         boolean isLastTableParent = false; 
699         if (lastTable != null) { 
700             if (lastTable.parent() != null) { 
701                 fosterParent = lastTable.parent(); 
702                 isLastTableParent = true; 
703             } else 
704                 fosterParent = aboveOnStack(lastTable); 
705         } else { // no table == frag 
706             fosterParent = stack.get(0); 
707         } 
708  
709         if (isLastTableParent) { 
710             Validate.notNull(lastTable); // last table cannot be null by this point. 
711             lastTable.before(in); 
712         } 
713         else 
714             fosterParent.appendChild(in); 
715     }
