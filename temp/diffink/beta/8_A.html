 56     List<Node> parseFragment(String inputFragment, Element context, String baseUri, ParseErrorList errors) { 
 57         // context may be null 
 58         state = HtmlTreeBuilderState.Initial; 
 59         initialiseParse(inputFragment, baseUri, errors); 
 60         contextElement = context; 
 61         fragmentParsing = true; 
 62         Element root = null; 
 63  
 64         if (context != null) { 
 65             if (context.ownerDocument() != null) // quirks setup: 
 66                 doc.quirksMode(context.ownerDocument().quirksMode()); 
 67  
 68             // initialise the tokeniser state: 
 69             String contextTag = context.tagName(); 
 70             if (StringUtil.in(contextTag, "title", "textarea")) 
 71                 tokeniser.transition(TokeniserState.Rcdata); 
 72             else if (StringUtil.in(contextTag, "iframe", "noembed", "noframes", "style", "xmp")) 
 73                 tokeniser.transition(TokeniserState.Rawtext); 
 74             else if (contextTag.equals("script")) 
 75                 tokeniser.transition(TokeniserState.ScriptData); 
 76             else if (contextTag.equals(("noscript"))) 
 77                 tokeniser.transition(TokeniserState.Data); // if scripting enabled, rawtext 
 78             else if (contextTag.equals("plaintext")) 
 79                 tokeniser.transition(TokeniserState.Data); 
 80             else 
 81                 tokeniser.transition(TokeniserState.Data); // default 
 82  
 83             root = new Element(Tag.valueOf("html"), baseUri); 
 84             doc.appendChild(root); 
 85             stack.add(root); 
 86             resetInsertionMode(); 
 87  
 88             // setup form element to nearest form on context (up ancestor chain). ensures form controls are associated 
 89             // with form correctly 
 90             Elements contextChain = context.parents(); 
 91             contextChain.add(0, context); 
 92             for (Element parent: contextChain) { 
 93                 if (parent instanceof FormElement) { 
 94                     formElement = (FormElement) parent; 
 95                     break; 
 96                 } 
 97             } 
 98         } 
 99  
100         runParser(); 
101         if (context != null && root != null) 
102             return root.childNodes(); 
103         else 
104             return doc.childNodes(); 
105     }

171     Element insert(Token.StartTag startTag) { 
172         // handle empty unknown tags 
173         // when the spec expects an empty tag, will directly hit insertEmpty, so won't generate this fake end tag. 
174         if (startTag.isSelfClosing()) { 
175             Element el = insertEmpty(startTag); 
176             stack.add(el); 
177             tokeniser.transition(TokeniserState.Data); // handles <script />, otherwise needs breakout steps from script data 
178             tokeniser.emit(emptyEnd.reset().name(el.tagName()));  // ensure we get out of whatever state we are in. emitted for yielded processing 
179             return el; 
180         } 
181          
182         Element el = new Element(Tag.valueOf(startTag.name()), baseUri, startTag.attributes); 
183         insert(el); 
184         return el; 
185     }

240     private void insertNode(Node node) { 
241         // if the stack hasn't been set up yet, elements (doctype, comments) go into the doc 
242         if (stack.size() == 0) 
243             doc.appendChild(node); 
244         else if (isFosterInserts()) 
245             insertInFosterParent(node); 
246         else 
247             currentElement().appendChild(node); 
248  
249         // connect form controls to their form element 
250         if (node instanceof Element && ((Element) node).tag().isFormListed()) { 
251             if (formElement != null) 
252                 formElement.addElement((Element) node); 
253         }

382     void resetInsertionMode() { 
383         boolean last = false; 
384         for (int pos = stack.size() -1; pos >= 0; pos--) { 
385             Element node = stack.get(pos); 
386             if (pos == 0) { 
387                 last = true; 
388                 node = contextElement; 
389             } 
390             String name = node.nodeName(); 
391             if ("select".equals(name)) { 
392                 transition(HtmlTreeBuilderState.InSelect); 
393                 break; // frag 
394             } else if (("td".equals(name) || "td".equals(name) && !last)) { 
395                 transition(HtmlTreeBuilderState.InCell); 
396                 break; 
397             } else if ("tr".equals(name)) { 
398                 transition(HtmlTreeBuilderState.InRow); 
399                 break; 
400             } else if ("tbody".equals(name) || "thead".equals(name) || "tfoot".equals(name)) { 
401                 transition(HtmlTreeBuilderState.InTableBody); 
402                 break; 
403             } else if ("caption".equals(name)) { 
404                 transition(HtmlTreeBuilderState.InCaption); 
405                 break; 
406             } else if ("colgroup".equals(name)) { 
407                 transition(HtmlTreeBuilderState.InColumnGroup); 
408                 break; // frag 
409             } else if ("table".equals(name)) { 
410                 transition(HtmlTreeBuilderState.InTable); 
411                 break; 
412             } else if ("head".equals(name)) { 
413                 transition(HtmlTreeBuilderState.InBody); 
414                 break; // frag 
415             } else if ("body".equals(name)) { 
416                 transition(HtmlTreeBuilderState.InBody); 
417                 break; 
418             } else if ("frameset".equals(name)) { 
419                 transition(HtmlTreeBuilderState.InFrameset); 
420                 break; // frag 
421             } else if ("html".equals(name)) { 
422                 transition(HtmlTreeBuilderState.BeforeHead); 
423                 break; // frag 
424             } else if (last) { 
425                 transition(HtmlTreeBuilderState.InBody); 
426                 break; // frag 
427             } 
428         }

569         int numSeen = 0; 
570         for (int pos = formattingElements.size() -1; pos >= 0; pos--) {

594     void reconstructFormattingElements() { 
595         Element last = lastFormattingElement(); 
596         if (last == null || onStack(last)) 
597             return; 
598  
599         Element entry = last; 
600         int size = formattingElements.size(); 
601         int pos = size - 1; 
602         boolean skip = false; 
603         while (true) { 
604             if (pos == 0) { // step 4. if none before, skip to 8 
605                 skip = true; 
606                 break; 
607             } 
608             entry = formattingElements.get(--pos); // step 5. one earlier than entry 
609             if (entry == null || onStack(entry)) // step 6 - neither marker nor on stack 
610                 break; // jump to 8, else continue back to 4 
611         } 
612         while(true) { 
613             if (!skip) // step 7: on later than entry 
614                 entry = formattingElements.get(++pos); 
615             Validate.notNull(entry); // should not occur, as we break at last element 
616  
617             // 8. create new element from element, 9 insert into current node, onto stack 
618             skip = false; // can only skip increment from 4. 
619             Element newEl = insertStartTag(entry.nodeName()); // todo: avoid fostering here? 
620             // newEl.namespace(entry.namespace()); // todo: namespaces 
621             newEl.attributes().addAll(entry.attributes()); 
622  
623             // 10. replace entry with new entry 
624             formattingElements.set(pos, newEl); 
625  
626             // 11 
627             if (pos == size-1) // if not last entry in list, jump to 7 
628                 break; 
629         } 
630     }

 56     List<Node> parseFragment(String inputFragment, Element context, String baseUri, ParseErrorList errors) { 
 57         // context may be null 
 58         state = HtmlTreeBuilderState.Initial; 
 59         initialiseParse(inputFragment, baseUri, errors); 
 60         contextElement = context; 
 61         fragmentParsing = true; 
 62         Element root = null; 
 63  
 64         if (context != null) { 
 65             if (context.ownerDocument() != null) // quirks setup: 
 66                 doc.quirksMode(context.ownerDocument().quirksMode()); 
 67  
 68             // initialise the tokeniser state: 
 69             String contextTag = context.tagName(); 
 70             if (StringUtil.in(contextTag, "title", "textarea")) 
 71                 tokeniser.transition(TokeniserState.Rcdata); 
 72             else if (StringUtil.in(contextTag, "iframe", "noembed", "noframes", "style", "xmp")) 
 73                 tokeniser.transition(TokeniserState.Rawtext); 
 74             else if (contextTag.equals("script")) 
 75                 tokeniser.transition(TokeniserState.ScriptData); 
 76             else if (contextTag.equals(("noscript"))) 
 77                 tokeniser.transition(TokeniserState.Data); // if scripting enabled, rawtext 
 78             else if (contextTag.equals("plaintext")) 
 79                 tokeniser.transition(TokeniserState.Data); 
 80             else 
 81                 tokeniser.transition(TokeniserState.Data); // default

401                 transition(HtmlTreeBuilderState.InTableBody); 
402                 break; 
403             } else if ("caption".equals(name)) { 
404                 transition(HtmlTreeBuilderState.InCaption); 
405                 break; 
406             } else if ("colgroup".equals(name)) { 
407                 transition(HtmlTreeBuilderState.InColumnGroup); 
408                 break; // frag 
409             } else if ("table".equals(name)) { 
410                 transition(HtmlTreeBuilderState.InTable); 
411                 break; 
412             } else if ("head".equals(name)) { 
413                 transition(HtmlTreeBuilderState.InBody); 
414                 break; // frag

417                 break;

594     void reconstructFormattingElements() { 
595         Element last = lastFormattingElement(); 
596         if (last == null || onStack(last)) 
597             return; 
598  
599         Element entry = last; 
600         int size = formattingElements.size(); 
601         int pos = size - 1; 
602         boolean skip = false; 
603         while (true) { 
604             if (pos == 0) { // step 4. if none before, skip to 8 
605                 skip = true; 
606                 break; 
607             } 
608             entry = formattingElements.get(--pos); // step 5. one earlier than entry 
609             if (entry == null || onStack(entry)) // step 6 - neither marker nor on stack 
610                 break; // jump to 8, else continue back to 4 
611         } 
612         while(true) { 
613             if (!skip) // step 7: on later than entry 
614                 entry = formattingElements.get(++pos); 
615             Validate.notNull(entry); // should not occur, as we break at last element 
616  
617             // 8. create new element from element, 9 insert into current node, onto stack 
618             skip = false; // can only skip increment from 4. 
619             Element newEl = insertStartTag(entry.nodeName()); // todo: avoid fostering here? 
620             // newEl.namespace(entry.namespace()); // todo: namespaces 
621             newEl.attributes().addAll(entry.attributes()); 
622  
623             // 10. replace entry with new entry 
624             formattingElements.set(pos, newEl); 
625  
626             // 11 
627             if (pos == size-1) // if not last entry in list, jump to 7 
628                 break; 
629         } 
630     }

673     void insertInFosterParent(Node in) { 
674         Element fosterParent; 
675         Element lastTable = getFromStack("table"); 
676         boolean isLastTableParent = false; 
677         if (lastTable != null) { 
678             if (lastTable.parent() != null) { 
679                 fosterParent = lastTable.parent(); 
680                 isLastTableParent = true; 
681             } else 
682                 fosterParent = aboveOnStack(lastTable); 
683         } else { // no table == frag 
684             fosterParent = stack.get(0); 
685         } 
686  
687         if (isLastTableParent) { 
688             Validate.notNull(lastTable); // last table cannot be null by this point. 
689             lastTable.before(in); 
690         } 
691         else 
692             fosterParent.appendChild(in); 
693     }
